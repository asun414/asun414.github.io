# 发布流程

## 发布前

先同步远程版本，避免覆盖其他设备上的更新：

```powershell
Set-Location "E:\BaiduSyncdisk\个人网站"
git pull --ff-only origin main
```

编辑完成后执行质量检查：

```powershell
npm run check
npm run build
git status
```

确认没有敏感文件、临时文件或错误内容后提交：

```powershell
git add .
git commit -m "Update research notes"
git push origin main
```

提交说明应简短具体，例如 `Update CV and publication list`，不要反复使用 `update` 或无意义编号。

## 自动部署

推送到 `main` 后，`.github/workflows/deploy.yml` 会构建并发布网站。可在 GitHub 仓库的 **Actions** 页面查看进度：

[https://github.com/asun414/asun414.github.io/actions](https://github.com/asun414/asun414.github.io/actions)

工作流显示绿色成功标记后检查：

- [英文首页](https://hlsun.org/)
- [中文首页](https://hlsun.org/zh/)
- [Notes](https://hlsun.org/notes/)
- 本次新增或修改的页面

浏览器仍显示旧内容时，可强制刷新（Windows：`Ctrl+F5`），或等待 Cloudflare/GitHub Pages 缓存更新。

## 在另一台电脑维护

安装 Git、Node.js LTS 和 VS Code，然后克隆仓库：

```powershell
git clone https://github.com/asun414/asun414.github.io.git
Set-Location "asun414.github.io"
corepack pnpm install
npm run dev
```

不要在两台电脑同时编辑同一文件。每次开始先 `git pull --ff-only`，每次结束及时提交并推送。
